# wolysh v0.4.1: portable Linux x86_64 release

This patch release fixes the distributed binary's CPU target. The v0.4.0
archive was built for the GitHub runner's native CPU and can terminate with
`SIGILL` on other x86_64 machines. v0.4.1 builds and tests the archive for
baseline x86_64, without requiring the runner's optional instruction extensions.

Upgrade to v0.4.1 if you downloaded v0.4.0. The v0.4.0 tag remains unchanged.
Native `parallel`, fail-fast queueing, JSONL reports, syntax checks, and all
other 0.4.0 features are included.

## Install or upgrade

Download `wolysh-v0.4.1-linux-x86_64.tar.gz` and its `.sha256` file:

```sh
sha256sum -c wolysh-v0.4.1-linux-x86_64.tar.gz.sha256
tar -xzf wolysh-v0.4.1-linux-x86_64.tar.gz
mkdir -p "$HOME/.local/bin"
install -m 0755 wolysh-v0.4.1-linux-x86_64/wsh "$HOME/.local/bin/wsh"
"$HOME/.local/bin/wsh" --version
```

Ensure `$HOME/.local/bin` is on `PATH`. Source builds still require Zig 0.16.0.
To build a portable binary from source:

```sh
zig build -Doptimize=ReleaseFast -Dtarget=x86_64-linux -Dcpu=baseline
```

## Verification

CI and the release workflow use the same baseline x86_64 target for unit tests
and the ReleaseFast binary, followed by the interactive and compatibility suites.
The release workflow verifies the tag against the binary version before packaging.

The published archive is downloaded and checked against its SHA-256 file, then
tested on a separate x86_64 machine with syntax-check and parallel/report smoke
tests. Benchmark samples packaged with this patch describe the v0.4.0 native
development build, not the baseline archive; see their recorded versions,
checksums, and methodology before applying the ratios to another build.

- 148 unit tests
- 37 interactive checks
- 40 compatibility tests
