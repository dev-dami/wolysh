# wolysh v0.7.0: smarter suggestions, a completion menu and multi-line editing

Wolysh 0.7.0 makes the interactive shell feel closer to fish.

- **Suggestions ranked by context.** The grey suggestion now prefers a
  command you ran in this directory right after the command you just ran,
  then one run in this directory, then the newest anywhere. Commands whose
  latest run failed come last. `let suggest = "recent"` keeps the old
  newest-match behaviour.
- **A completion menu.** An ambiguous Tab opens a menu below the line
  instead of printing the list into the scrollback. Tab, Shift-Tab and the
  arrow keys move through it, the line follows the selection, Enter keeps it
  and Esc puts back what you typed. Each candidate has a short description:
  a builtin's summary, `function`, `alias: <text>`, `keyword` or `command`, a
  variable's value, or `directory`, `link` or `executable`.
- **Multi-line and wrapped editing.** Up and Down move by screen row inside a
  long or multi-line command and keep their column. Home, End and the kill
  keys act on the current line, and Alt-Enter inserts a new line. A command
  taller than the screen, wide characters at the margin, and resizing are all
  drawn correctly.

## Highlights

```sh
# in ~/project, after `cd ~/project`
make            # suggests what you ran here after cd, not the newest `make`

ls src/<Tab>    # menu below the line; Tab/arrows to pick, Enter to keep
echo $P<Tab>    # $PATH, $PWD... each with its value

if true {       # Enter continues the block
  echo one      # Up/Down move between rows, Alt-Enter inserts a line
}
```

- **History format v3.** Each entry now records its time, directory and the
  command before it, plus a status line with its exit status and duration.
  Times survive a restart, so `HISTTIMEFORMAT` shows when commands ran.
  Shells sharing the file take turns changing it, so none loses another's
  commands.
- **Completion.** Command completion offers reserved words such as `while`,
  as Bash's `compgen -c` does, and no longer offers plain files that cannot
  run.
- **Keys.** End and Ctrl-E accept the suggestion. Esc or an arrow key ends a
  Ctrl-R search on the match. vi `j`/`k` move by row, and `0 ^ $ I A D C` act
  on the current line.
- **Starship.** `eval -- "..."` now works as in Bash, so
  `eval "$(starship init bash)"` starts without an error.

## Upgrading from 0.6

- **The history file is upgraded to format v3** the first time a command is
  entered. wsh 0.6.0 and earlier read a v3 file wrongly. Don't run old and
  new versions against the same history file; to go back, keep a copy
  (`cp ~/.local/share/wsh/history ~/.local/share/wsh/history.bak`) before
  upgrading.
- Up and Down inside a multi-line or wrapped command move the cursor instead
  of browsing history. Ctrl-P and Ctrl-N always browse history.
- Continuation prompts indent by nesting depth rather than line number.

## Known limits

- On resize, terminals that re-wrap text and terminals that don't can't be
  told apart without a cursor-position query, so the redraw starts as high as
  either needs and may clear a line or two of earlier output above the
  prompt.
- Completion from man pages, a plugin manager and a native prompt protocol
  are planned but not in this release.

## Install or upgrade

Download `wolysh-v0.7.0-linux-x86_64.tar.gz` and its `.sha256` file:

```sh
sha256sum -c wolysh-v0.7.0-linux-x86_64.tar.gz.sha256
tar -xzf wolysh-v0.7.0-linux-x86_64.tar.gz
mkdir -p "$HOME/.local/bin"
install -m 0755 wolysh-v0.7.0-linux-x86_64/wsh "$HOME/.local/bin/wsh"
"$HOME/.local/bin/wsh" --version
```

## Verification

CI and the release workflow build for baseline x86_64, check that the tag
matches `wsh --version`, and run the unit, interactive and compatibility suites
before packaging.

- 423 unit tests
- 39 interactive checks
- 43 new screen tests that drive wsh through a terminal emulator and check
  exactly what is on screen: the completion menu, multi-line and wrapped
  editing, and resizing
- The compatibility suites, which compare wsh with Bash case by case, all
  pass unchanged

No benchmark was recorded for this release; the changes are to interactive
editing and history, not to script execution.
